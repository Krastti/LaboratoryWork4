# LaboratoryWork4

## Build

```bash
cmake -S . -B build
cmake --build build
```

Пример работы кода с трансфинитными индексами:

```bash
cmake --build build --target LaboratoryWork4
```

Интерфейс турникета

```bash
cmake --build build --target TurnstileInterface
```

Unit Tests:

```bash
cmake --build build --target LaboratoryWork4Tests
```
